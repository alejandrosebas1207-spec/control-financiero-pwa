# Identidad de las cuentas

Los logotipos se usan para identificar las cuentas personales del usuario. Las marcas pertenecen a sus respectivos titulares.

- Banco Guayaquil: SVG original de https://www.bancoguayaquil.com/favicon.svg
- Deuna: SVG original de https://www.deuna.ec/_astro/logo-deuna-sm.C523izCn.svg, enlazado desde https://www.deuna.ec/
- Mastercard: logotipo de https://upload.wikimedia.org/wikipedia/commons/2/2a/Mastercard-logo.svg. Referencia de marca: https://www.mastercard.com/brandcenter/us/en/download-artwork.html
- Efectivo: ilustración SVG propia de billetes.

La superficie dorada y el chip decorativo son un diseño propio para este panel; no reproducen una tarjeta emitida por un banco específico. No se muestran números ni datos de tarjeta inventados.
